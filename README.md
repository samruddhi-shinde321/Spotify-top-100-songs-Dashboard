# Spotify-top-100-songs-Dashboard
# 🎵 Spotify Top 100 Songs – Data Analysis & Power BI Dashboard

## 📌 Project Overview
This project focuses on exploring and analyzing Spotify's Top 100 Songs (2018) dataset to identify music trends, understand artist representation, and explore relationships between different song audio attributes.

The dataset was sourced from **Maven Analytics**, initially explored using Microsoft Excel, and then analyzed and visualized using Microsoft Power BI.

The project consists of two interactive dashboard pages, each focusing on different aspects of the dataset.

## 🎯 Project Objectives
- Analyze the representation of artists in Spotify's Top 100 Songs.
- Identify artists with the highest number of songs in the Top 100.
- Compare the number of artists with "Lil" and "DJ" in their names.
- Explore relationships between different song audio attributes.
- Identify which audio attributes have the most variability and which tend to be most similar.

## 📊 Dashboard Pages & Analysis

### 1. Overview Dashboard
This page provides a summary of the dataset through key performance indicators (KPIs) and visual comparisons.

**Key Elements:**
- Total Songs
- Total Song Names
- Total Artists
- Average Danceability
- Average Energy

**Analysis Covered:**
- Top Artists by Number of Songs in the Top 100.
- Comparison of artists with "Lil" and "DJ" in their names.
- Overview of key song statistics through KPI cards.

### 2. Song Attributes Analysis
This page focuses on understanding the relationships and variations among different audio characteristics of the songs.

**Analysis Covered:**
- **Song Attributes Correlation Matrix:** Explores relationships between Acousticness, Danceability, Energy, Instrumentalness, Liveness, Loudness, Speechiness, Tempo, and Valence.
- **Attribute Variability:** Compares the variability of different song attributes.
- **Attribute Similarity:** Examines which audio attributes tend to have more similar values across the Top 100 songs.
